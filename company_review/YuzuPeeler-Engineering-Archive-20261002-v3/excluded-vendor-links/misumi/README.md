# MISUMI conveyor reference

The SVKA conveyor catalog is available from the manufacturer:
[SV Series conveyor catalog](https://us.misumi-ec.com/pdf/fa/2019/2019_US_1254.pdf).
It documents conveyor dimensions including the 30 mm pulley used for Motor 6
belt-speed conversion. Confirm the installed pulley and drive gearing before
using the supplied scaling. The PDF is not included in this operator bundle.
